# Switch Docker base from linuxserver/bun to node:24-alpine

Replaced `linuxserver/bun:latest` with `node:24-alpine` and install Bun via the official install script. Avoids unreliable or unavailable oven/bun and linuxserver/bun images on Docker Hub.

- Build stages use a shared `bun-base` stage with `apk` deps and `curl | bash` install.
- Plain `Dockerfile` runner copies Bun from the build stage (same arch).
- `Dockerfile.platform` runner installs Bun on the target platform for cross-arch builds.
